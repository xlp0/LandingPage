## Outcome

Responsive UI Lab is restyled directly from StageShow craft (`tools/stageshow/playground/viewer.tsx`, `references/craft.md`, `references/looks.md`) and gains the interactive Bombadil dashboard over the event-triggering handle API built in `SPRINT-SSG-04`. Every control across the active host routes (`responsive-lab.astro`, `index.astro`, `sprint-registry.astro`, `fiber-inspector.astro`, `js/harness/`, `src/islands/`, and `scripts/penpot-render.mjs`, leaving untouched legacy `app.astro`) uses uniform `14px` and `16px` single-stroke inline SVG icons (`js/ui/icons.js`, with zero platform emojis in active host controls or Penpot nav/lattice tests), sentence-case labels without trailing colons, `5`-surface tonal steps with high-contrast `--lab-control-border`, local WOFF2 `Inter` / `JetBrains Mono` fonts, solid active segment states, and four explicit dock modes (`Explore | Guided | Bombadil | Verify`) backed by declarative `[hidden]` switching. `src/islands/BombadilDashboardIsland.jsx` (`client:visible`, `0 B` cold load) joins as the explicitly registered `8th` thin stateless Preact view backed by `js/harness/bombadil-client.js`, alongside opt-in `PresentationController` header toggles across Lab, Portal, Sprint Registry, and Fiber Inspector.
