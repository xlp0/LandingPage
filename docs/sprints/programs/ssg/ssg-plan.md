## Outcome

Program SSG (`StageShow GUI Layout, Bombadil Dashboard, and Viewport Coherence`) embeds StageShow `1.1.1` as both an automated layout and rehearsal gate (`scripts/stageshow/run.mjs`) and an authored demo kit (`tools/stageshow/`, `.agents/skills/stageshow/`, `public/stageshow/`). Responsive UI Lab is modeled directly after StageShow's layout craft (`tools/stageshow/playground/viewer.tsx`, `references/craft.md`, `references/framing.md`, `references/looks.md`, `references/kit.md`, `references/motion.md`, and `kit/stage.css`) while integrating `@antithesishq/bombadil@0.7.10` as an interactive property-testing dashboard driven by Triad event-triggering handles (`urn:mcard:bombadil:*`), `/api/test-runs/bombadil/*` endpoints, and `window.__lab.bombadil` browser events. Across `1440px`, `820px`, `390px`, and `358px` widths, every workbench preset, custom dimension, orientation switch, frame bezel, operating mode, Bombadil dashboard control, and host page renders with `1:1` inner iframe layout pixels, `0` off-screen clipped controls (`r.left >= -1 && r.right <= innerWidth + 1`), and `documentElement.scrollWidth <= innerWidth + 1` while keeping Playwright, Bombadil, and Petri net gates green.

## Who this is for

Developers and TEA (`Test Engineering and Architecture`) engineers testing applications in Responsive UI Lab get true `1:1` inner viewport pixels, uninverted desktop and mobile orientations, parametric hardware bezels, a StageShow-aligned single-band workbench shell, and live one-click Bombadil exploration, shrinking, and coverage handles directly beside the stage. End users opening the Sovereign MCard portal on phone, tablet, or desktop screens see a static-poster-backed showcase framed above live cards with zero vertical voids or colliding top bars.

The engineer who maintains LandingPage next inherits one pure viewport geometry module, unified `14px` and `16px` inline SVG iconography, five-surface StageShow-aligned CSS tokens, typed MCard handle schemas for Bombadil test automation, and deterministic StageShow sweep and Playwright layout gates.

## Glossary

- **BMAD, CLM, and TEA.** `BMAD` (`Breakthrough Method of Agile AI-Driven Development`) assigns sprint ownership across PM, UX, Architect, Developer, Tech Writer, and `TEA` (`Test Engineering and Architecture`). `CLM` (`Cubical Logic Model`) and `GQC`/`BPV`/`STY` refer to prior LandingPage architectural and style programs recorded under `docs/sprints/programs/`.
- **Place and Transition.** Petri net nodes and arcs declared in `src/net/workbench-net.yaml` (Layer 1) and `tests/fixtures/spa-test-target.graph.json` (Layer 4). Every browser `fetch` or route switch maps to declared Transitions. Intra-Place UI controls (such as mode tabs on `/responsive-lab.html`) stay off `workbench-net.yaml` to obey `check-net.mjs` `self-loop-transition`.
- **Triad and MCard handle.** Content-addressed SQLite store (`storage.put` and `storage.bindHandle` in `server/test-run-api.mjs`) binding mutable URN handles (`urn:mcard:...`) to immutable BLAKE3 hashes under append-only invariant `INV-REF-03`.
- **Bombadil, LTL, and quiescence.** `@antithesishq/bombadil@0.7.10` temporal-logic (`LTL`) browser explorer wrapped by `scripts/bombadil/run.mjs`, `canary.mjs`, and `trace-to-net.mjs`. `Quiescence` is Bombadil's stability predicate requiring no pending network fetches or long DOM mutation bursts before extracting temporal properties.
- **Event-triggering handle.** A named MCard handle (`urn:mcard:bombadil:trigger:<target>`) paired with `/api/test-runs/bombadil/trigger`, `window.__lab.bombadil`, and DOM `lab:bombadil-command` / `lab:bombadil-state` CustomEvents that starts, streams, stops, and shrinks Bombadil property runs from the LandingPage dashboard.
- **StageShow `1.1.1`.** Vendored UI craft rubric, `layout.mjs` / `film.mjs` / `jumps.mjs` / `class-clash.mjs` audit scripts, playground reference (`viewer.tsx`), and kit primitives under `tools/stageshow/` and `.agents/skills/stageshow/`.
- **Geometry invariant `INV-SSG-GEOM`.** Guarantees that `#controlled-panel-frame` renders parametric bezels outside a `content-box` `.stage-screen-slot` so `#mission-control-iframe` always has exact `targetW x targetH` CSS layout pixels with zero bezel subtraction from inner iframe coordinates.
- **Island lock and `astro-wrapped` pages.** `src/pages/responsive-lab.astro` hydrates named Preact islands (`7` today, expanding explicitly to `8` in `SPRINT-SSG-05` with `BombadilDashboardIsland`) enforced by `tests/features/responsive-lab-islands.spec.js` and `scripts/check-docs.mjs`. Other host routes remain `astro-wrapped` with `0` `<astro-island>` elements enforced by `tests/performance/place-bytes.mjs`.
- **Layout freeze.** `tests/features/layout-freeze.spec.js` compares DOM bounding boxes across `6` pages and `5` Type Lattice viewports against `tests/baselines/layout-baseline.json` with `<= 0.5px` tolerance.
- **PresentationController.** `js/runtime/presentation-controller.js` owning `data-theme` (`dark | light | high-contrast`), `data-power-mode` (`balanced | energy-saving`), and reduced-motion WAAPI degradation.

## StageShow layout expertise applied to LandingPage

StageShow separates **transferable UI layout craft** (applied across the LandingPage workbench and host routes) from **marketing-demo house style** (confined to authored illustrations under `public/stageshow/` on `/index.html?noredirect=1`).

### Transferable layout architecture across workbench and host routes

1. **Playground-modeled workbench anatomy (`tools/stageshow/playground/viewer.tsx` and `viewer.css`).**
   - `header.lab-navbar` (`44px` height, single band) places `Back to Portal` and product title on the left, and `Arrangement` (`Sidebar | Stacked`), `PresentationController` toggles (`#theme-toggle-btn`, `#power-toggle-btn`), `Mission Control`, and `Pop out` on the right.
   - `aside#workbench-controls-dock` opens with one segmented `role="tablist"` mode bar (`Explore | Guided | Bombadil | Verify`) above `[hidden]`-switched task panels so controls never pile vertically.
   - `main#lab-stage-container` mirrors `.pg-preview` in three stacked bands `(toolbar + well + transport)`. `.stage-toolbar` holds `#stage-target-place`, `#controlled-frame-dim` (`tabular-nums`), `Rotate` (`#btn-rotate-viewport`), `Scale: Fit | Actual (1:1)`, and `Safe-area guides`. `.stage-well` renders one recessed `--lab-well` canvas framing `.stage-scale-rig` -> parametric hardware bezel -> `content-box` `.stage-screen-slot` -> `#mission-control-iframe`. `.stage-transport` sits directly below `.stage-well` (always visible across all `4` modes) housing `RecordingRibbonIsland` (`Start / Pause / Resume / Stop`, `0 ev`, fidelity tier) and `#bombadil-transport-pill` (live Bombadil job badge that focuses the `Bombadil` tab when clicked).
2. **Five-surface token and step hierarchy (`tools/stageshow/references/looks.md` and `kit/stage.css`).**
   - Define `--lab-canvas`, `--lab-well`, `--lab-surface`, `--lab-chrome`, and `--lab-raised` across dark, light, and high-contrast themes. On dark surfaces, depth comes from lightness steps rather than heavy card borders (`craft.md:111-114`).
   - Active segmented thumbs take a solid surface step (`[aria-pressed="true"]`, `[aria-selected="true"]`), never translucent overlays. Radii follow StageShow (`6px` item, `8px` input/segment, `10px` popover, `12px` window, `999px` pill); upstream `kit/stage.css:101-102` uses `--ss-control: 34px` and `--ss-row: 26px`, adapted to LandingPage `34px` inputs and `28px` compact buttons with `scrollbar-gutter: stable` and `font-variant-numeric: tabular-nums`.
3. **Single-weight SVG iconography and typographic restraint (`craft.md:21, 24, 47, 52-55, 86, 91-96`).**
   - Replace every emoji and Unicode dingbat glyph in controls (`js/ui/icons.js`, `app-config.json:17,27,37`, `js/harness/lab-toolbar.js`, `js/harness/viewport-stage.js:129`, `src/pages/`, `src/islands/`, `scripts/penpot-render.mjs`, and `tests/`) with uniform inline SVGs (`--lab-icon-sm: 14px`, `--lab-icon-md: 16px`, `1.5px` stroke, `flex: none`, opaque `--lab-icon`, `aria-hidden="true"`).
   - Use sentence-case labels without trailing colons, `8px` to `12px` control spacing, `12px` card insets, and `1` large hero counter (`craft.md:21`) paired with compact secondary rows in Bombadil telemetry.
4. **Device frame contract (`INV-SSG-GEOM`, `tools/stageshow/references/kit.md`).**
   - Upstream `tools/stageshow/kit/` exports only `Window` (`38px` bar, `hairline` chrome) and fixed-size portrait `Phone` (`402x874` / `412x915`) scaled as illustrations, with no `Tablet` or multi-size system. LandingPage renders parametric CSS hardware bezels (`phone-ios`, `phone-android`, `tablet`, `browser-window`, `hairline-ruler`, `unframed`) across `3` CSS archetypes (`phone`, `tablet`, `window/unframed`, with user-saved custom `wearable` mapped to `hairline-ruler`) strictly outside `box-sizing: content-box` `.stage-screen-slot` so `#mission-control-iframe.clientWidth === targetW` and `clientHeight === targetH` in CSS layout pixels, while outer `.stage-scale-rig` scales `(targetW + chromeInsets.x, targetH + chromeInsets.y)` via `computeScale`.
